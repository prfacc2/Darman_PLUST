# 🏥 درمان پلاس (DarmanPlus)

**سامانه پذیرش و مدیریت درمانگاه — نسخه ۱.۹۱.۰**

برنامه دسکتاپ ویندوز با C++ خالص (Win32 API) — بدون هیچ وابستگی خارجی، یک فایل EXE واحد.

---

## ⚠️ راهنمای مدل‌های هوش مصنوعی (مهم — اول این را بخوانید)

اگر شما یک مدل هوش مصنوعی هستید که این مخزن (یا بکاپ آن) به شما داده شده تا روی آن کار کنید:

1. **ابتدا این فایل‌ها را به ترتیب بخوانید:**
   - **`AGENTS.md` — قانون کار روی این مخزن. الزامی و اولین فایل.**
   - `docs/ARCHITECTURE.md` — نقشهٔ راه: هر بخش کدام فایل است و مالک هر لایه کیست
   - `docs/DESIGN_SYSTEM.md` — پالت رنگ و قوانین ظاهری (تنها مرجع رنگ برنامه)
   - `docs/PROJECT_GUIDE.md` — ساختار کامل کد، معماری، و ساز و کار هر بخش
   - `docs/CHANGELOG.md` — تاریخچه تغییرات هر نسخه
   - `docs/PROMPT.md` — پرامپت اصلی و تکمیلی که برنامه بر اساس آن ساخته شده

2. **قوانین الزامی (شرح کامل در `AGENTS.md`):**
   - ❌ **هیچ بخش، آیتم، صفحه یا قابلیت موجود را حذف یا دستکاری نکنید** مگر اینکه صریحاً خواسته شده باشد. این مهم‌ترین قانون است: نسخه‌هایی که فقط قرار بود یک صفحه را عوض کنند، در گذشته بی‌صدا آیتم‌های صفحه‌های دیگر را پاک کرده‌اند.
   - ✅ فقط قابلیت جدید **اضافه** کنید یا باگ مشخص‌شده را رفع کنید.
   - ✅ **هر رنگ باید از `docs/DESIGN_SYSTEM.md` بیاید.** رنگ دلبخواهی اضافه نکنید.
   - ✅ **لایهٔ CSS جدید روی لایه‌های قبلی انبار نکنید.** هر چیز یک مالک دارد؛ همان فایل را عوض کنید (`AGENTS.md` بخش ۴).
   - ✅ محاسبات مالی (`billing.cpp`, `adComputeBill`) و قالب فایل‌های داده را نشکنید؛ ستون فقط به **انتهای** فایل اضافه می‌شود.
   - ✅ نام بخش/خدمت/بیمه را در کد **hard-code نکنید** — این‌ها در «مدیریت» تعریف می‌شوند.
   - ✅ سبک کدنویسی موجود (Win32 خالص، فونت Vazirmatn، تم روشن/تیره، RTL فارسی) را حفظ کنید.
   - ✅ بعد از هر تغییر، `docs/CHANGELOG.md` را به‌روز کنید (چه کاری، چرا، در کدام فایل).
   - ✅ خروجی همیشه باید **یک EXE واحد** باشد که روی x86 و x64 و ویندوز 7 تا 11+ کار کند (با `build.sh` بیلد کنید).
   - ✅ بعد از بیلد موفق، EXE جدید را در پوشه `build/` قرار دهید.

3. **برای بیلد:** `./build.sh` (نیاز به `g++-mingw-w64-i686` روی لینوکس) — جزئیات در PROJECT_GUIDE.

4. **قرارداد UI خودکار بررسی می‌شود:** `build.sh` پیش از کامپایل،
   `scripts/check_ui_contract.py` را اجرا می‌کند. این اسکریپت بررسی می‌کند که
   هیچ صفحه‌ای آیتم‌های لازمش را از دست نداده، ثبت منابع (`app.rc` / inliner /
   `index.html`) هم‌خوان است، CSS روی **هر دو موتور** (WebView2 و
   MSHTML/Trident) رندر می‌شود، لایه‌بندی تم دست‌نخورده است، و رنگ‌های
   ردشده (بنفش/صورتی/کِرِم) برنگشته‌اند. **بیلد قرمز = تحویل ناتمام.**
   هرگز خطای این اسکریپت را با حذف کردن خودِ بررسی «رفع» نکنید.

## 🆕 تازه‌های نسخهٔ ۱.۶۷.۰

- **پذیرش کاملاً تعبیه‌شده و پایدار**: HTML/CSS/JS از منابع خود EXE بارگذاری می‌شود؛ هیچ سرور یا پورت localhost برای پذیرش یا طراح چاپ اجرا نمی‌شود و شکست موتور وب به فرم نیتیو سالم برمی‌گردد.
- **چاپ دقیق خدمات در هر ۳۰ قالب**: نام خدمت، شرح، تعداد و مبلغ از همان پذیرش چاپ می‌شوند؛ جدول بر اساس تعداد واقعی ردیف‌ها رشد می‌کند، شرح بلند می‌شکند و دادهٔ نمونه یا ردیف تکراری چاپ نمی‌شود.
- **بازطراحی پذیرش بیمار**: رابط سه‌ستونهٔ سریع، خوانا و واکنش‌گرا با تم سفید/آبی متعادل، تم تیرهٔ هماهنگ، صورت‌حساب واضح و عملیات ثبت/چاپ در ریل راست.
- **رفع تداخل ظاهری نیتیو**: دکمه‌های سفید با متن سفید، مدال‌های سفید در تم تیره، آثار مربع در گوشه‌های گرد و لوگوی خالی رفع شدند.
- **طراح چاپ بدون مرورگر خارجی**: طراح کامل نیتیو با ذخیره، import/export، جدول خدمات و اتصال طرح به بخش مستقیماً در برنامه اجرا می‌شود.

## 📦 دانلود و اجرا

فایل اجرایی آماده: [`build/DarmanPlus.exe`](build/DarmanPlus.exe)

- یک فایل EXE واحد — **هم روی ویندوز 32 بیتی و هم 64 بیتی** اجرا می‌شود.
- سازگار با ویندوز **7 / 8 / 8.1 / 10 / 11** و جدیدتر.
- نیاز به نصب ندارد؛ کنار EXE پوشه‌های `data/` و `logs/` خودکار ساخته می‌شوند.
- روی سخت‌افزار ضعیف (RAM 2GB / CPU دو هسته‌ای) هم روان کار می‌کند.

### شروع سریع
1. `DarmanPlus.exe` را اجرا کنید (تمام‌صفحه باز می‌شود).
2. در صفحه اصلی `Ctrl + P + N` را نگه دارید → پنل ادمین → ورود با `prf` / `prf123`.
3. کاربر بسازید (مثلاً بخش: «دندانپزشکی»، نوع: پذیرش).
4. خروج (دکمه ✕ بالا راست) → «پذیرش درمانگاه» → ورود با کاربر ساخته‌شده → انتخاب شیفت → ثبت پذیرش.

## 🛠️ بیلد از سورس

```bash
# روی لینوکس (Debian/Ubuntu):
sudo apt install g++-mingw-w64-i686
./build.sh        # خروجی: build/DarmanPlus.exe
```

روی ویندوز با MSYS2/MinGW32 هم همان فرمان‌های داخل `build.sh` قابل اجراست.

## 📂 ساختار مخزن

```
├── src/             ← سورس C++ (Win32 خالص)
├── fonts/           ← فونت Vazirmatn (داخل EXE تعبیه می‌شود)
├── build/           ← خروجی EXE نهایی
├── docs/            ← مستندات کامل (PROJECT_GUIDE / CHANGELOG / PROMPT)
├── update/          ← فایل version.txt برای آپدیت از راه دور
└── build.sh         ← اسکریپت بیلد
```

## 🔄 آپدیت از راه دور — راه‌اندازی سرور

فایل `update/version.txt` در این مخزن (یا هر سرور HTTP دیگر):
```
1.67.0
https://github.com/prfacc2/AZADI_TEB/releases/download/v1.67.0/DarmanPlus.exe
```
(خط اول = آخرین نسخه، خط دوم = لینک دانلود EXE جدید.)
آدرس پیش‌فرض، raw گیت‌هاب همین مخزن است؛ برای تغییر، در `data/settings.ini` کلید `update_url` را تنظیم کنید.
