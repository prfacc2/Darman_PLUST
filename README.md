# 🏥 درمان پلاس (DarmanPlus)

**سامانه پذیرش و مدیریت درمانگاه — نسخه ۱.۹۵.۰**

برنامه دسکتاپ ویندوز با C++ خالص (Win32 API) — بدون هیچ وابستگی خارجی، یک فایل EXE واحد.

## 🆕 تازه‌های نسخهٔ ۱.۹۲.۰

- **پالت «Soft Medical Glassmorphism» v1.93**: Ice White بک‌گراند، شیشه نیمه‌شفاف، آبی پزشکی `#2D5FE6`، متن سرمه‌ای، سایه نرم، gradient ملایم.
- **تم نئونی (Cyberpunk)**: تم سوم با accent فیروزه‌ای نئونی `#00F0FF`، سبز/صورتی نئونی، بک‌گراند آبی-مشکی عمیق.
- **کارتابل پیام HTML**: منوی همبرگری، جستجو، آرشیو، سنجاق، چاپ، ذخیره، پاسخ — حرفه‌ای و sync شده با کل برنامه.
- **فلش ماشین حساب**: فشردن کلید کیبورد → دکمه متناظر فلش می‌زند.
- **فلگ «ثبت پذیرش در صندوق»**: تیک در تعریف بخش برای اضافه‌شدن به تب‌های صندوق.
- **تنظیمات fullscreen**: کل صفحه را فرا می‌گیرد؛ «تنظیمات پذیرش» و «پیام‌های ذخیره» حذف و منتقل شد.
- **تم تیره روی همه سطح‌ها**: HTML و C++ هماهنگ، متن/لیبل سفید در تم تیره.
- **بهینه‌سازی لود پذیرش**: performers و queue در init ادغام شد (حذف 2 round-trip).
- **رفع باگ‌های پذیرش**: آیکن صورت حساب، خطوط رنگی عملیات/چاپ، کارت‌های وسط.
- **صندوق**: دکمه‌های شیفت غیرفعال‌شدنی، تاریخ/ساعت دو خطی در ردیف دکمه‌ها، تب‌های glassmorphism.
- **چاپ دقیق خدمات در هر ۳۰ قالب**: نام خدمت، شرح، تعداد و مبلغ از همان پذیرش چاپ می‌شوند.

## 📦 دانلود و اجرا

فایل اجرایی آماده: [`build/DarmanPlus.exe`](build/DarmanPlus.exe)

- یک فایل EXE واحد — **هم روی ویندوز 32 بیتی و هم 64 بیتی** اجرا می‌شود.
- سازگار با ویندوز **7 / 8 / 8.1 / 10 / 11** و جدیدتر.
- نیاز به نصب ندارد؛ کنار EXE پوشه‌های `data/` و `logs/` خودکار ساخته می‌شوند.
- روی سخت‌افزار ضعیف (RAM 2GB / CPU دو هسته‌ای) هم روان کار می‌کند.

### شروع سریع
1. `DarmanPlus.exe` را اجرا کنید (تمام‌صفحه باز می‌شود).
2. در صفحه اصلی `Ctrl + P + N` را نگه دارید → پنل ادمین → ورود با `prf` / `prf123`.
3. کاربر بسازید (مثلاً بخش: «دندانپزشکی»، نوع: پذیرش).
4. خروج (دکمه ✕ بالا راست) → «پذیرش درمانگاه» → ورود با کاربر ساخته‌شده → انتخاب شیفت → ثبت پذیرش.

## 🛠️ بیلد از سورس

```bash
# روی لینوکس (Debian/Ubuntu):
sudo apt install g++-mingw-w64-i686
./build.sh        # خروجی: build/DarmanPlus.exe
```

روی ویندوز با MSYS2/MinGW32 هم همان فرمان‌های داخل `build.sh` قابل اجراست.

## 📂 ساختار مخزن

```
├── src/             ← سورس C++ (Win32 خالص)
├── assets/          ← دارایی‌های تعبیه‌شده HTML/CSS/JS (پذیرش/صندوق/ابزارها/داشبورد)
├── fonts/           ← فونت Vazirmatn (داخل EXE تعبیه می‌شود)
├── build/           ← خروجی EXE نهایی
├── docs/            ← مستندات (PROJECT_GUIDE / CHANGELOG / DESIGN_SYSTEM / ARCHITECTURE)
├── scripts/         ← تست‌ها و اسکریپت‌های کمکی
├── update/          ← فایل version.txt برای آپدیت از راه دور
└── build.sh         ← اسکریپت بیلد
```

> **برای مدل‌های هوش مصنوعی:** قبل از هر تغییری، [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) و [`docs/DESIGN_SYSTEM.md`](docs/DESIGN_SYSTEM.md) را بخوانید. این فایل‌ها قوانین ایمنی و پالت رنگی استاندارد را تعریف می‌کنند.

```
1.92.0
```
